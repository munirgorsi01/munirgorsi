# Muhammad Munir — Cybersecurity & IT Support Portfolio

A responsive, static portfolio website built with HTML, CSS and JavaScript. It is designed for GitHub Pages hosting and includes a CV PDF download.

## Files
- `index.html` — page content and structure
- `styles.css` — responsive dark navy / electric blue design
- `script.js` — mobile navigation and current-year footer
- `assets/Muhammad-Munir-CV.pdf` — CV download
- `assets/design-concept-preview.png` — generated visual design reference (not used as page background)

## Preview locally
Open this folder in Visual Studio Code. For a local preview, install the **Live Server** extension, right-click `index.html`, and choose **Open with Live Server**. Or run a simple local server from this folder:
`python -m http.server 8000`
Then visit `http://localhost:8000`.

## Publish with GitHub Pages
1. Create a GitHub repository, for example `muhammad-munir-portfolio`.
2. Upload the contents of this folder (not the enclosing ZIP) to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then Save.
6. Wait for the Pages deployment and open the URL shown in Settings → Pages.
7. GitHub Pages normally provides HTTPS automatically. Turn on **Enforce HTTPS** when the option becomes available.

## Before publishing — please review
- Confirm that all dates, job titles, qualification names and certification statuses are current and accurate.
- The CV says LetsDefend SOC Fundamentals, CompTIA A+, CompTIA Security+ and AWS Certified Cloud Practitioner are ongoing; the site labels them as ongoing rather than completed.
- The CV does not provide project dates, public project URLs or detailed outcomes. Add these only when you can verify them.
- The additional face-to-face and online text-message customer service experience mentioned in conversation should be confirmed with role details before being presented as a specific achievement.
- Replace or remove any contact details you do not want publicly visible. A public portfolio can be indexed by search engines.
- Add a professional headshot only if you want one; none has been invented or included.

## Important
This is a static website, so it does not need Node.js, a database, or a server at runtime. GitHub Pages can host it directly. The included PDF is the CV supplied for this project.
